CruXEngagement Canvas · Owner concern → pilot → lock-in

1. Owner concern

Start here. Their words, not your tools.

2. Success in 30–60 days

One metric + one observable change.

3. Constraints

Hours, staff, lease, family labor, brand rules.

4. Translate to a system problem

Demand · Capacity · Flow · Standards · Cost · Management cadence

5. Evidence to gather

Watch one peak (30–60 min)
Pull 2–4 weeks POS / schedule data
Map bottleneck station
Note waste / remakes / waits
Compare schedule vs. demand curve

6. Root causes (max 5)

Rank by impact × ease.

7. This week’s pilot

One change. Owner, who, by when.

8. Engagement phases

Intake

Concern → metric → scope boundary. Do not open with software.

Diagnose

Hypothesis → observe + data → 1-page causes & ranked opportunities.

Pilot

Run one high-leverage change for 2–4 weeks. Measure before/after.

Lock-in

Simple standard + weekly 20-min ops review so gains stick.

9. Metric baseline → target

10. Risks / “not now”

Ideas parked outside this engagement.

11. Next touchpoint

Date, agenda, decision needed.
